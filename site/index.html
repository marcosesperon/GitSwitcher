macOS menu bar app · free & open sourceApp de barra de menús · libre y gratuita

Switch GitHub accounts in one click. Cambia de cuenta de GitHub con un clic.

GitSwitcher shows your active gh account in the menu bar and switches to another one instantly — exactly like gh auth switch, without opening a terminal. GitSwitcher muestra en la barra de menús tu cuenta activa de gh y cambia a otra al momento — igual que gh auth switch, sin abrir la terminal.

InstallInstalar Source codeCódigo fuente
brew install --cask marcosesperon/tap/gitswitcher
~ — zsh

          Pruébalo: pulsa Work en la barra de arriba.
        

      

    

  


  
  

    

      
WhyPor qué

      
A friendly face for gh.Una cara amable para gh.

      

        gh already supports several accounts per host and, as your git credential helper, decides which account git push uses. GitSwitcher just puts that one click away.
        gh ya admite varias cuentas por servidor y, como credential helper de git, decide con qué cuenta se hace git push. GitSwitcher solo lo deja a un clic.
      

      

        

          

          
No tokens storedNo guarda tokens

          
Accounts come from gh auth status. Credentials stay in gh's keychain entries; GitSwitcher never sees them.Las cuentas salen de gh auth status. Las credenciales siguen en el llavero de gh; GitSwitcher nunca las ve.

        

        

          

          
Always in syncSiempre sincronizada

          
Switch from the terminal and the menu bar updates by itself. Sign in a new account and it shows up.Cambia desde la terminal y la barra se actualiza sola. Inicia sesión con otra cuenta y aparece.

        

        

          

          
Small on purposePequeña a propósito

          
One menu, one settings window, no background services. In 9 languages.Un menú, una ventana de ajustes y nada en segundo plano. En 9 idiomas.

        

        

          

          
Make it yoursHazla tuya

          
An icon and a color per account — a blue briefcase for work, a green house for personal — so you know which one is active at a glance.Un icono y un color por cuenta — un maletín azul para el trabajo, una casa verde para lo personal — para saber de un vistazo cuál está activa.

SetupConfiguración

      
Get your accounts in the menu.Tus cuentas, en el menú.

      

        Four steps, done once. The app's Settings › Guide checks each one on your Mac and can run the commands for you.
        Cuatro pasos que se hacen una vez. En la app, Ajustes › Guía comprueba cada uno en tu Mac y puede lanzar los comandos por ti.
      

      
    
        
  1. 
          
    Install GitHub CLIInstala GitHub CLI
    
          
    Skip it if you installed GitSwitcher with Homebrew. Other options atSáltatelo si instalaste GitSwitcher con Homebrew. Otras opciones en cli.github.com.
    
          
    brew install gh
    
        
    2. 
        
  2. 
          
    Sign in with each accountInicia sesión con cada cuenta
    
          
    Run it once per GitHub account (work, personal…). gh opens the browser and keeps the credentials in the macOS keychain. In the app: Settings › Accounts › Add Account…Ejecútalo una vez por cada cuenta de GitHub (trabajo, personal…). gh abre el navegador y guarda las credenciales en el llavero de macOS. En la app: Ajustes › Cuentas › Añadir cuenta…
    
          
    gh auth login
    
        
    3. 
        
  3. 
          
    Let git use the active accountHaz que git use la cuenta activa
    
          
    Makes gh provide the credentials for git push and pull on github.com, so they follow the account you pick in the menu.Hace que gh dé las credenciales para git push y pull en github.com, así siguen a la cuenta que elijas en el menú.
    
          
    gh auth setup-git
    
        
    4. 
        
  4. 
          
    Commit authorAutor de los commitsoptionalopcional
    
          
    Switching accounts doesn't change who signs your commits. Either turn on Settings › Accounts › Also change the git author when switching, or set the author per folder with includeIf:Cambiar de cuenta no cambia quién firma tus commits. O activas Ajustes › Cuentas › Cambiar también el autor de git, o fijas el autor por carpeta con includeIf:
    

    # ~/.gitconfig
[includeIf "gitdir:~/work/"]
    path = ~/.gitconfig-work

# ~/.gitconfig-work
[user]
    name  = Octo Cat
    email = octo@work.example
